## 🎯 About

We often know *what* we want to say — but not always *how* to say it right.

**MindVoice AI** listens (literally, via voice or text), analyzes the emotion and intent behind your message, scores your communication, and rewrites your reply in the tone that fits the moment — friendly, professional, or polite. Built for the way people actually talk in India — switching fluidly between English, Tamil, and Tanglish.

## ✨ Features

| Category | Feature |
|---|---|
| 🧠 **Core Coaching** | AI Communication Coach, Communication Score, Communication Tips |

| 💬 **Reply Styles** | Friendly Reply · Professional Reply · Polite Reply |
| 🎙️ **Input Modes** | Voice Input, Text Input |

## ⚙️ How It Works

```

🎤 / ⌨️  User Input (Voice or Text)
        │
        ▼
🌐  Language Detection (English / Tamil / Tanglish)
        │
        ▼
🧠  Emotion + Intent Analysis  (Llama 3.3 70B via Groq)
        │
        ▼
⭐  Communication Score + 💡 Tips
        │
        ▼
💬  Reply Suggestions → Friendly | Professional | Polite

```

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/<your-username>/mindvoice-ai.git
cd mindvoice-ai

# Install dependencies
pip install -r requirements.txt

# Add your Groq API key
export GROQ_API_KEY="your-api-key-here"

# Run the app
streamlit run app.py
```
